[[staplus-auth]]
== STAplus Authentication Requirements


=== Overview

To regulate access to entities using CRUD operations, implementations may wish to use information from user / client application authentication to make access control decisions. 

In addition, some implementations may wish to link the authentication identifier (e.g., `REMOTE_USER`) with the `Party/authId`. Therefore, the STAplus authentication must provide service-wide unique user identifiers.

[requirement]
====
[%metadata]
identifier:: {identifier}/req/authentication/id

The STAplus authentication SHALL provide a user identifier add:[that is] permanent for del:[same] add:[a given] user del:[but different for each user] add:[and unique across users].
====

[requirement]
====
[%metadata]
identifier:: {identifier-corrigendum}/req/authentication/id-read

The STAplus implementation SHALL ensure that the `Party/authId` property is add:[not] exposed in any response add:[, including MQTT payloads,] and can add:[not] be used in STA operators such as `$select` add:[or `$expand` or `$orderby`] unless the requesting user is represented by the `Party`. add:[The property SHALL NOT be used in `$filter` except as specified in `{identifier-corrigendum}/req/authentication/me`.] add:[An MQTT message SHALL NOT contain `Party/authId` unless the MQTT client is authenticated as the user represented by that `Party`.]
====

[requirement]
====
[%metadata]
identifier:: {identifier-corrigendum}/req/authentication/id-create

The STAplus implementation SHALL overwrite any existing value and SHALL set the `Party/authId` property with the user's identification value provided by the authentication (e.g., `REMOTE_USER`). add:[The implementation SHALL set `Party/@iot.id` to a random identifier that is not correlated to the user identification.]
====

[requirement]
====
[%metadata]
identifier:: {identifier}/req/authentication/id-update

The STAplus implementation SHALL ensure that the `Party/authId` property cannot be changed (ensure read-only).
====

[requirement]
====
[%metadata]
identifier:: {identifier}/req/authentication/id-delete

The STAplus implementation SHALL ensure that the `Party/authId` property cannot be deleted.
====

NOTE: add:[Requirement `{identifier-corrigendum}/req/authentication/me` belongs to this Requirements Class. It is specified after the last original requirement of this Standard (see <<req-authentication-me>>) so that the requirement numbers of STAplus 1.0 remain unchanged.]
