[[staplus-business-logic]]
== STAplus Business Logic Requirements

=== Overview

The Business Logic Requirements Class is inherited from <<OGC22-022r2>>, including the GDPR compliance note for `Location` and `HistoricalLocation` of a `Thing` owned by an individual `Party`, and the License attribution note that system `License` entities are templates and that each use is an instance with `attributionText` filled. The full GDPR Conformance Class of this Standard is specified in <<staplus-gdpr>>.
