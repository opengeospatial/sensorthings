[appendix,obligation="normative"]
== Conformance Class Abstract Test Suite

This normative section defines the STAplus 1.1 Conformance Class tests. These tests apply to the entity types defined in this Standard. An implementation that claims this Standard also passes the Abstract Test Suite of <<OGC22-022r2>>.

[NOTE]
A STAplus 1.1 compliant implementation must also be compliant with the SensorThings API conformance as defined in <<OGC15-078r6>>, respectively <<OGC18-088>>, and with STAplus 1.0.1 as defined in <<OGC22-022r2>>.

=== STAplus *Landing Page* Conformance Class Tests


[conformance_test]
====
[%metadata]
identifier:: {identifier}/conf/landing-page/encoding-type
target:: {identifier}/conf/landing-page

target:: {identifier}/req/encoding-type


test-purpose:: To verify that the implementation advertises the supported geometry `encodingType` ValueCodes as a JSON array on the landing page.
test-method:: Inspect the landing page (the root URI):

part:: Find the JSON array in the `serverSettings` object with the name `{identifier}/req/encoding-type`.

part:: Verify that the value is a JSON array and that each element is a media type listed in <<media-types>>.

part:: Verify that the implementation accepts each advertised ValueCode as the `encodingType` of a geometry property of `FeatureOfInterest`, `Location`, or `PartyLocation`.
====

[conformance_test]
====
[%metadata]
identifier:: {identifier}/conf/landing-page/environment
target:: {identifier}/conf/landing-page

target:: {identifier}/req/environment


test-purpose:: To verify that the implementation advertises the accepted `PartyLocation` `environment` EnvCodes as a JSON array on the landing page.
test-method:: Inspect the landing page (the root URI):

part:: Find the JSON array in the `serverSettings` object with the name `{identifier}/req/environment`.

part:: Verify that the value is a JSON array.

part:: If the array is not empty, construct a `PartyLocation` entity for each advertised EnvCode and verify that the implementation accepts that `environment` value. Construct a `PartyLocation` entity whose `environment` is not in the array and verify that the implementation rejects it.

part:: If the array is empty, construct a `PartyLocation` entity with an `environment` value and verify that the implementation does not constrain the code list.
====

part:: Create an entity instance by linking to existing entities with a single request, check if the server responds as defined in this Standard.


part:: Create an entity instance that does not follow the integrity constraints by linking to existing entities with a single request, check if the server responds as defined in this Standard.
