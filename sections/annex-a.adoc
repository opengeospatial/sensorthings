== Conformance Class Abstract Test Suite

=== Conformance Class GDPR

This subclause defines the abstract tests of the GDPR conformance class. There is one abstract test for each requirement of the GDPR requirements class. The requesters U1, U2, U3 and A and the entities P1, P2 and D1 are defined in <<clause-conventions-requesters,Clause 5>>.

NOTE: An implementation of this Profile must also pass the tests of the STAplus 1.0.1 conformance classes listed as _required_ in <<tab-staplus-dependencies>>, and the tests of the conditional classes it claims.

The test environment has to be able to obtain credentials that resolve to a given user and to a given client identifier with a given software identifier and software version.
