=== Identifiers
The normative provisions in this standard are denoted by the URI

`{identifier}`

All requirements and conformance tests that appear in this document are denoted by absolute URIs which are compliant with this base.

Provisions inherited from STAplus 1.0.1 are denoted by the URI `{identifier-101}`.

=== JSON encoding of relation names

Association role names in the Clause 7 relation tables use STA PascalCase (`PartyLocation`, `Observations`, `PartyActivities`, `Shares`, `Recipients`, `ReceivedShares`) as used in the JSON encoding. UML association ends in <<OGC22-022r2>> and in the STAplus 1.1 UML may use camelCase (`partyLocation`, `observations`, `partyActivities`, `shares`, `recipients`, `receivedShares`).
