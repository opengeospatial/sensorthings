== Scope
This Standard extends <<OGC18-088>> with the `Cell` entity type and with the corresponding associations from del:[`Observation`, `Datastream`, and `MultiDatastream`] add:[`Datastream` and `MultiDatastream`]. It also defines how an implementation advertises the deployed Discrete Global Grid System (DGGS), how Create, Update, and Delete of a `Cell` are restricted so that cells remain uniform, and how an implementation calculates aggregate values from raw observations del:[linked to a cell] add:[whose `Datastream`s are linked to a cell].

This Standard does not replace <<OGC18-088>>. All SensorThings Sensing requirements of <<OGC18-088>> remain in force unless this Standard explicitly extends them. This Standard does not require a particular DGGS (H3, Geohash, S2, ISEA3H, or any other). The deployed grid system and the del:[cell-create boundary] add:[cells boundary] are advertised as specified in the del:[<<cell,Cell>>] add:[<<system,System>>] Requirements Class. add:[The cells boundary is the area within which the implementation materializes cells.]

This Standard can also be used with <<OGC22-022r2>> (STAplus 1.0.1). <<OGC22-022r2>> is a normative reference for an implementation that claims the <<conformance_class_staplus,STAplus>> Conformance Class. del:[<<OGC22-022r2>> replaces STAplus 1.0 (OGC 22-022r1). ]This Standard del:[inherits the Party Requirements Class at `{identifier-staplus}/req-class/party`] add:[depends on the Core Conformance Class of <<OGC22-022r2>> at `{identifier-staplus}/conf/core`]. An implementation that combines this extension with STAplus remains subject to the STAplus requirements that it claims.

This Standard does not specify a particular storage architecture, database product, or internal scheduling mechanism for aggregation.

The number of possible cells at a fine zone level is very large. For H3, the number of cells at resolution _r_ is 2 + 120 × 7^r^ (see https://h3geo.org/docs/core-library/restable/[H3 cell statistics]). That is 33,897,029,882 cells at resolution 10, 237,279,209,162 cells at resolution 11, and 1,660,954,464,122 cells at resolution 12. For Geohash, each character of the identifier selects one of 32 cells. A Geohash of length 15 therefore names one of 32^15^ = 37,778,931,862,957,161,709,568 cells.
