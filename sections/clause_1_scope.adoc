== Scope

This Standard specifies a profile with extension of the OGC SensorThings API Extension: STAplus 1.0 Standard, corrigendum 1.0.1 (<<OGC22-022r2>>), for deployments that process personal data subject to the European General Data Protection Regulation (<<GDPR>>).

The Profile

* identifies which properties of the STAplus and SensorThings API data models contain direct personal data, in particular the properties of the `Party` entity type and the `attributionText` and `description` of party-specific `License` instances;
* identifies which location and time properties contain indirect personal data when they belong to an entity that is attributable to a `Party` representing a natural person;
* specifies the additional entity type `Agreement`, which records the authorization of a data subject for storing and publishing specific personal data, and its life cycle including withdrawal and expiry;
* specifies that an effective `Agreement` is the legal basis required before an implementation stores or releases direct personal data, for example `Party/displayName` or `License/attributionText`, before it releases precise location and time values, and before it releases free-text values such as `Thing/description` that the user has written;
* specifies the generalization or withholding of location and time values that are released without an `Agreement`;
* specifies how queries, `$expand`, `$count` and MQTT subscriptions are prevented from disclosing values that are not released, and that a request whose `$filter` or `$orderby` references `License/attributionText` is rejected;
* specifies the technical support for the data subject rights of access, rectification and erasure, and the advertisement of a privacy notice;
* specifies that the Party roles `institutional` and `system`, which take entities out of the scope of the Profile, can only be assigned to identities managed by the operator;
* specifies which STAplus 1.0.1 conformance classes an implementation of the mandatory GDPR conformance class has to implement;
* specifies, in the optional Accepted Clients conformance class, a public per-endpoint catalog of accepted client applications and their write profiles, the rejection of write requests from other clients, the validation of written content against declared JSON Schemas, the verification that a declared absence of free text is enforced by those schemas, and the binding of each Datastream and MultiDatastream to the write profile under which it was created; and
* specifies, in the optional DGGS conformance class, spatial obfuscation with the cells of the OGC SensorThings API Extension: DGGS 1.0, including release at zone levels chosen by the operator or the data subject, privacy zones, control of Cell associations and fine Cells, client-side obfuscation, and minimum-contributor and differencing rules for DGGS aggregates.

The Profile applies to entities that are attributable to a `Party` whose `role` is `individual`. Entities that are attributable only to institutional or system parties are out of scope, because the GDPR protects natural persons.

The Profile does not specify organisational measures of the controller, the content of consent texts, the classification of observation results and parameters, or the processing of personal data by systems other than the STAplus implementation.
