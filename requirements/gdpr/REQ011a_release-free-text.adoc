[requirement]
.Release of free-text values
====
[%metadata]
identifier:: http://www.opengis.net/spec/sensorthings-staplus-gdpr/1.0/req/gdpr/release-free-text
part:: The implementation SHALL NOT release a value of a free-text property (see <<tab-register>>) of an entity attributable to a Party `P` whose `role` is `individual` to a requester `r` that is not the data subject of `P`, unless an Agreement of `P` exists that is effective for that property path, the operation `publish` and `r`, or the value is exempt according to the last part of this requirement.
part:: This requirement SHALL apply to every response, including responses to requests with `$select`, `$expand` at any depth, navigation links, and MQTT payloads.
part:: Where a value is not released, the implementation SHALL release the empty string for a property that is mandatory in the version of the SensorThings API or STAplus that it implements, and SHALL omit the property otherwise. It SHALL NOT release any other placeholder value.
part:: The storage of a free-text value SHALL NOT require an Agreement.
part:: A value SHALL be exempt if it was generated by the implementation, or if the implementation claims the Accepted Clients conformance class and the value is exempt according to <<req_accepted-clients_free-text-policy>>.
====
